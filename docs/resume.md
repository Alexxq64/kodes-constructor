## Проблемы и решения (Troubleshooting)

### Проблема 1: Терминал VS Code "проглатывает" заглавные буквы
- **Симптом:** При вводе команд в PowerShell заглавные буквы игнорировались. Из-за этого в URL репозитория `Alexxq64` первая буква `A` превратилась в строчную.
- **Решение:** Проблема связана с работой модуля PSReadLine в PowerShell. В качестве временного решения использовалось копирование команд из чата. В будущем рекомендуется обновить PSReadLine командой `Install-Module PSReadLine -Force` или использовать Git Bash.

### Проблема 2: Ошибка `remote: Repository not found` при пуше
- **Симптом:** Git не мог найти репозиторий на GitHub.
- **Причина:** Из-за "проглоченной" буквы (см. Проблему 1) адрес `origin` в локальном Git сохранился как `lexxq64/kodes-constructor`, а не `Alexxq64/kodes-constructor`.
- **Решение:** Команда `git remote add origin ...` выдала ошибку, так как origin уже существовал. Правильное решение — перезаписать существующий адрес командой:
  `git remote set-url origin https://github.com/Alexxq64/kodes-constructor.git`
  После этого пуш прошел успешно.

### Проблема 3: Ошибка 404 (favicon.ico)
- **Симптом:** В консоли браузера красная ошибка `Failed to load resource: 404 (Not Found)`.
- **Решение:** Это не ошибка кода. Браузер пытается найти иконку для вкладки сайта, не находит её и сообщает об этом. На работу 3D-сцены это никак не влияет. Игнорируем.

## Обновление от 1 ноября 2026 года (Шаг 6: Загрузка 3D-модели)

**Текущий статус:** 
3 этап (Взаимодействие). Модель успешно загружена, отображается, реагирует на свет, отбрасывает тени и меняет цвет.

**Сделано:**
- Скачана и добавлена 3D-модель футболки (`t-shirt_-_lengan_pendek.glb`) в папку `assets`. Модель содержит 3 отдельных Mesh-объекта (всего 19 043 вершины, 34 692 треугольника).
- Написана функция `loadJersey` для загрузки модели через `GLTFLoader`.
- Решена проблема с масштабом и позиционированием: исходная модель имела гигантские размеры (высота ~672 единицы) и была смещена по оси Y (~1318 единиц). Все три части модели были извлечены из `gltf.scene`, сохранены, отцентрированы через `geometry.translate` и отмасштабированы (`scale.set(0.003, 0.003, 0.003)`).
- После центрирования и масштабирования модель повернута лицом к камере и поставлена на ноги (`rotation.x = -Math.PI / 2`).
- Включены тени: добавлен невидимый пол (`ShadowMaterial`), настроен направленный свет с `castShadow = true`.
- Исправлена логика смены цвета: теперь материалы всех частей модели собираются в массив `jerseyMaterials`, и при клике цвет меняется у всех сразу.

**Проблемы и решения:**

*   **Невидимая 3D-модель:** 
    Модель загружалась без ошибок (в консоли было `Футболка успешно загружена`), но на экране отсутствовала.
    *   *Диагностика:* Написан код, который вывел в консоль реальные габариты (`Box3`), количество вершин и координаты. Выяснилось, что модель имеет высоту около 672 единиц и смещена по оси Y на 1318 единиц.
    *   *Решение:* Все три части модели были извлечены из `gltf.scene` и сохранены. Для каждой части выполнено центрирование через `geometry.translate(-center.x, -center.y, -center.z)`. После этого каждая часть отмасштабирована (`scale.set(0.003, 0.003, 0.003)`). Порядок операций: извлечение → центрирование → масштабирование → поворот.

*   **Неправильная ориентация модели:** 
    Футболка отображалась лежа или вверх ногами.
    *   *Решение:* После центрирования и масштабирования добавлен поворот `newMesh.rotation.x = -Math.PI / 2`.

*   **Отсутствие теней:** 
    Модель выглядела плоской.
    *   *Решение:* Включен `renderer.shadowMap.enabled = true`, добавлен невидимый пол с `ShadowMaterial`, настроен `DirectionalLight` с `castShadow = true`.

*   **Смена цвета не работала:** 
    При клике на кнопку цвет менялся в консоли, но не на экране.
    *   *Причина:* Материал сохранялся только от последнего кусочка модели, а не от всех.
    *   *Решение:* Создан массив `jerseyMaterials`, в который собираются все материалы при загрузке. При клике перебираются все элементы массива и меняется их цвет.

*   **Ошибка `remote: Repository not found` при пуше в Git:** 
    Возникла из-за того, что терминал «проглотил» заглавную букву в имени пользователя GitHub (`Alexxq64` превратилось в `lexxq64`).
    *   *Решение:* Использована команда `git remote set-url origin ...` для перезаписи адреса.

**Файлы:**
- `scene.js` — содержит всю 3D-логику (сцена, камера, свет, тени, загрузка модели, смена цвета).
- `index.html` — разметка и панель управления (кнопки цветов).
- `main.js` — точка входа, вызывает `initScene()`.
- `assets/t-shirt_-_lengan_pendek.glb` — 3D-модель футболки.
