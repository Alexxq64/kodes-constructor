## Проблемы и решения (Troubleshooting)

### Проблема 1: Терминал VS Code "проглатывает" заглавные буквы
- **Симптом:** При вводе команд в PowerShell заглавные буквы игнорировались. Из-за этого в URL репозитория `Alexxq64` первая буква `A` превратилась в строчную.
- **Решение:** Проблема связана с работой модуля PSReadLine в PowerShell. В качестве временного решения использовалось копирование команд из чата. В будущем рекомендуется обновить PSReadLine командой `Install-Module PSReadLine -Force` или использовать Git Bash.

### Проблема 2: Ошибка `remote: Repository not found` при пуше
- **Симптом:** Git не мог найти репозиторий на GitHub.
- **Причина:** Из-за "проглоченной" буквы (см. Проблему 1) адрес `origin` в локальном Git сохранился как `lexxq64/kodes-constructor`, а не `Alexxq64/kodes-constructor`.
- **Решение:** Команда `git remote add origin ...` выдала ошибку, так как origin уже существовал. Правильное решение — перезаписать существующий адрес командой:
  `git remote set-url origin https://github.com/Alexxq64/kodes-constructor.git`
  После этого пуш прошел успешно.

### Проблема 3: Ошибка 404 (favicon.ico)
- **Симптом:** В консоли браузера красная ошибка `Failed to load resource: 404 (Not Found)`.
- **Решение:** Это не ошибка кода. Браузер пытается найти иконку для вкладки сайта, не находит её и сообщает об этом. На работу 3D-сцены это никак не влияет. Игнорируем.

## Подробное описание выполненной работы и возникших проблем

### 1. Настройка окружения и Git
*   **Локальный сервер:** Браузеры блокируют загрузку ES6-модулей с локального диска (протокол `file://`). Запущен `npx serve`, который отдает файлы по `http://localhost:3000`.
*   **Ошибка Git `repository not found`:** Терминал VS Code «проглатывал» заглавные буквы (баг `PSReadLine`), из-за чего в URL репозитория `Alexxq64` превращалось в `lexxq64`.
*   **Решение:** Использована команда `git remote set-url origin ...` для принудительной замены неправильного адреса.
*   **Файл `.gitignore`:** Создан для исключения системного мусора (`node_modules`, `.vscode` и т.д.).

### 2. Проблема невидимой 3D-модели (Самая долгая отладка)
Модель `t-shirt_-_lengan_pendek.glb` загружалась (в консоли было `Футболка успешно загружена`), но на экране не отображалась.
*   **Ошибочная функция `Box3().setFromObject()`:** Мы пытались автоматически вычислить центр модели, но эта функция возвращала `Infinity` или некорректные координаты из-за сложной внутренней структуры файла. Из-за этого код сдвигал модель в «бесконечность».
*   **Диагностика:** Был написан временный код, который вывел в консоль:
    *   Количество `Mesh` (3 шт).
    *   Количество вершин (19 043) и треугольников (34 692).
    *   Реальные габариты (`min` и `max`).
    *   Координаты центра (смещение по Y было ~1318).
*   **Решение (Функция `loadJersey`):** Мы отказались от автоматического центрирования. Вместо этого мы извлекли чистую геометрию из каждого `Mesh`, сдвинули её через `geometry.translate(-center.x, -center.y, -center.z)`, и **принудительно** отмасштабировали (`scale.set(0.003, 0.003, 0.003)`).
*   **Ориентация:** Модель лежала «на спине». Мы повернули её лицом к камере: `newMesh.rotation.x = -Math.PI / 2`.

### 3. Проблема с тенями и светом
*   **Ошибочный подход:** Изначально использовался `MeshBasicMaterial`, который не реагирует на свет и не отбрасывает тени.
*   **Решение:** Заменен на `MeshStandardMaterial`. В рендерере включен `renderer.shadowMap.enabled = true`. Добавлен невидимый пол (`ShadowMaterial`) на уровне `y = -2`. Направленному свету (`DirectionalLight`) добавлено свойство `castShadow = true`.

### 4. Проблема смены цвета (Функция `setupUI`)
*   **Ошибочный подход:** При клике на кнопку цвет менялся, но визуально ничего не происходило. Это было связано с тем, что мы сохраняли ссылку только на материал **последнего** куска модели, а первые два оставались белыми. Кроме того, `color.set()` не всегда перерисовывает материал.
*   **Решение:** Создан глобальный массив `jerseyMaterials = []`. При загрузке модели все созданные материалы пушатся в этот массив (`jerseyMaterials.push(material)`). При клике на кнопку цикл `forEach` перебирает весь массив, меняет цвет (`mat.color.set(hexColor)`) и ставит флаг `mat.needsUpdate = true`, чтобы Three.js перерисовал сцену.

### 5. Проблема с логотипом (Функция `applyDecalLogo`)
Загрузка и наложение логотипа заняли много времени из-за разных подходов.

*   **Попытка 1 (Плоский спрайт):** Использовали `PlaneGeometry` (плоский квадрат). Логотип появлялся, но «висел в воздухе» и не повторял изгибы футболки. Если привязать его к футболке, он ломался из-за масштаба (0.003).
*   **Попытка 2 (DecalGeometry без координат):** Логотип «расползался с разрывами» (захватывал воротник) или вообще не появлялся.
*   **Решение (Рабочий вариант):** Мы используем `DecalGeometry` (3D-наклейку).
    *   При загрузке логотипа мы стреляем лучом (`Raycaster`) из камеры в центр экрана (`new THREE.Vector2(0, 0)`), чтобы найти точку на груди футболки.
    *   Создаем декаль с жестким размером `1x1x1` в этой точке и добавляем её в `scene` (а не внутрь футболки).
    *   **Важно:** Устанавливаем `currentDecalPosition.z += 0.01`, чтобы наклейка не сливалась с тканью (Z-fighting).
*   **Перетаскивание:** При движении мыши с зажатой кнопкой мы снова стреляем лучом в футболку, находим новую точку и **пересоздаем** `DecalGeometry` в этой точке.
*   **Масштабирование:** При прокрутке колесика мы меняем вектор `currentDecalSize` и снова пересоздаем `DecalGeometry`.
*   **Конфликт зума:** Чтобы колесико не крутило камеру, когда мы находимся над логотипом, мы добавили проверку в `pointermove`. Если луч пересекает логотип, ставим `controls.enableZoom = false`, иначе — `true`.

### 6. Ошибки в HTML/CSS и порядок загрузки
*   **Ошибка `Cannot read properties of null (reading 'addEventListener')`:** Скрипт пытался найти кнопку загрузки логотипа в HTML, но её там не было (забыли добавить).
*   **Решение:** В `index.html` добавлен скрытый `<input type="file">` и кнопка `<button id="upload-btn">`. Вызов функции `setupLogoUpload()` перенесен в самый конец `initScene()`, чтобы HTML гарантированно загрузился до того, как скрипт начнет искать кнопки.
