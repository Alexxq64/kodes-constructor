# Техническое задание: 3D Конструктор Спортивной Формы

## 1. Цель
Создать интерактивный 3D-конструктор на сайте (в перспективе — для Tilda), который позволяет клиенту собрать спортивную форму, визуализировать её и отправить заявку с готовым дизайном.

## 2. Основной функционал (Scope)
- [ ] Загрузка 3D-модели (футболка/шорты).
- [ ] Вращение и масштабирование модели мышкой (OrbitControls).
- [ ] Выбор цвета ткани из палитры.
- [ ] Загрузка логотипа клиента (PNG/SVG) и наложение на форму.
- [ ] Добавление текста (Фамилия, Номер) на спину.
- [ ] Кнопка «Получить расчёт»: сбор контактов (Имя, Телефон) и отправка данных вместе со скриншотом дизайна на сервер (или в CRM).

## 3. Технические ограничения
- **Стек:** HTML, CSS, JavaScript (Three.js).
- **Среда:** Разработка локально (VS Code). 
- **Деплой:** В итоге код должен быть адаптирован для вставки в один блок T123 на Tilda (поэтому в финале мы сделаем сборку).

## 4. Что НЕ входит в задачу (Out of scope)
- Сложная аналитика поведения пользователя.
- Интеграция с 1С или складом.
- Мобильное приложение.
